# 内置中文字体（渲染回退子集）

以下文件均为 SIL Open Font License 1.1 开源字体的 GB2312+ 常用字符子集，
按 OFL 修改版条款将内部字体名改为 PTK-*（PTK = PDF Toolkit）。

- 来源：Noto Sans CJK SC（SIL OFL 1.1）
- 许可：https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE

## noto-serif.woff2

- 来源：Noto Serif CJK SC（SIL OFL 1.1）
- 许可：https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/LICENSE
